# Contributing

Install the locked development environment with `uv sync --locked --extra dev`. Run `uv run pytest -q`, `uv run ruff check src tests examples` and `uv run ruff format --check src tests examples`.

Declare units, coordinate conventions, observability and model assumptions. Verify mechanics against conservation identities, independent formulations or measured fixtures. Keep truth outside sensor-based inference and retain unattainable demands and termination outcomes.

Make each commit a coherent model, check, interface, study or documentation change. Do not use empty commits or manufactured dates. Rebuild scientific evidence from one clean committed source after physical changes.
